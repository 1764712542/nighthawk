# 配置文件参考

`config.toml`、`tui.toml`、mcp.json、agent 文件的位置与作用。

## config.toml

`~/.nighthawk/config.toml`：providers、models、permissions、hooks、skills 等。

## tui.toml

TUI 主题/布局配置。

## mcp.json

项目级或全局 MCP server 配置。

## agent 文件

Markdown frontmatter 定义 agent profile。
