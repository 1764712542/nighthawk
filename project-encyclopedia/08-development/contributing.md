# 贡献指南

仓库 CONTRIBUTING 和 AGENTS 定义的贡献流程。

## 文档

`CONTRIBUTING.md` 和中文版 `CONTRIBUTING.zh-CN.md`。

## PR

PR 标题用 Conventional Commit；不要空泛描述。

## Changeset

完成后运行 gen-changesets skill 生成 changeset。

## 安全

公开文本使用中性占位符，不暴露内部标识。

## 证据与代码位置

- `CONTRIBUTING.md`
- `CONTRIBUTING.zh-CN.md`
- `.github/pull_request_template.md`
