# 对比 OpenCode

OpenCode 是开源的终端 coding agent，NightHawk 在安全引擎、服务端和协议层更深。

## 相同点

开源、终端 TUI、支持多模型、MCP。

## 工程规模

NightHawk 包含 kap-server、klient、minidb、transcript、native SEA 等；OpenCode 更轻。

## 安全

NightHawk 原生安全工具集是差异化点。

## 扩展

NightHawk 的 DI×Scope Feature 系统让内置能力可插拔可观测。
